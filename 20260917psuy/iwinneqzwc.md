# 小宝宝要做“智力测试”吗？

> 更新时间：2026-09-17 (UTC+8)

**智力测试**

 

 

许多来国妇婴儿保科就诊的宝妈和宝爸们，在宝宝被安排做发育评估时常常会问：“这是不是‘智力测试’呀？宝宝这么小，怎么做呀？”今天就来跟大家讲讲关于发育评估和智力测试的三个**“w”**：

**What：什么是“智力测试”？**

**Why：为什么要做？**

**How：结果怎么看？**

4周岁或以上才能叫**智力测试**。

4周岁以下则称为**发育评估**。发育评估包括**筛查性****发育测验和****诊断性****发育测验**。

筛查性发育测验有很多种工具可以使用，国内常用的有**0-6岁儿童智能发育筛查测验（DST）**、丹佛发育筛查测验（DDST）、年龄与发育进程问卷（ASQ）等。我院儿保科常用的发育筛查测验是DST。

**什么是DST？**

DST是我国自主编制、用于0-6岁儿童的智力筛查工具，与另一个常用的发育筛查工具DDST在内容上有不少相似的地方。但DST是结合我国国情编制，更加适合中国儿童。

DST量表包括120个项目，分为**运动、社会适应、智力**３个能区（如下表）。

**01**

**运动能区**

主要测定神经肌肉成熟状况，全身运动的发展，运动协调和平衡等。

**02**

**社会适应能力**

测定儿童对现实社会文化的反应能力和料理自己生活的能力。

**03**

**智力能区**

通过测定各种感知和认知活动了解儿童的智力发展水平。

测验时间长短，随试剂测试项目的数量和复杂性，儿童反应的敏捷性及测试者操作的熟练程度而异。平均测试时间约5-15分钟。

**为什么需要做DST?**

在宝宝的成长过程中，很多家长可能会有这样的体会或疑惑：

**别人家的孩子都已经会爬、站立了，**

**怎么自己家的宝宝还啥都不会****？**

经常有家长觉得宝宝在家里只要吃得好、长得好，一切正常。结果到儿保门诊就诊后才发现，6月龄宝宝还不会笑出声，8月龄还不会独立坐起。

因此，我们建议定期开展DST这类发育监测，目的就是希望能**早期发现发育偏离，做到早期诊断和早期干预**。

**如何看DST结果？**

发育商是评价幼儿发育状况的一种指数。发育商愈高，发育状况愈好。

**DQ和DST有什么关系呢？**

DST的结果，以DQ和MI（智力指数）两项分数表示，DQ是三个能区的原始分数总和对应的发育商，MI则是直接由智力能区的原始分数对应常模表中查出的。

**DST的结果怎样才算正常呢？**

一般情况下，DQ和MI都要在**85分以上**才能视为正常。但是在实际过程中，常常由于宝宝认生、饥饿等各种原因，导致状态不佳、不配合甚至哭闹不止。这种情况下，会影响测试结果的准确性，使测试分数较实际分数偏低。所以家长在测试前，最好保证宝宝处于一天中的最佳状态，这样更能反应宝宝的真实水平。

**DQ或MI低于85分，应该怎么办呢？**

我们需要了解宝宝测试时，是不是因为前面说的一些原因导致状态不好。如果是，那么建议再行测试。

若分数在70-85分，医生一般会根据宝宝的情况给予家长一些训练的指导。然后在家里加强训练后2-3个月，再次复测DST。

若在宝宝测试状态好的情况下，DQ或者MI低于70分，这种情况就往往提示宝宝可能有发育迟缓，建议进一步完善诊断性发育测验。

**什么是诊断性发育测试？**

**DST属于筛查性发育测验**，可以理解为筛查性发育测验是用来快速发现问题的。因测试内容少，测试时间也短，比较适合用于体检时进行筛查。

**诊断性发育测验，**用来确诊问题，因测试内容多，测试时间长，适合用于筛查后进一步确诊有无问题的。

常用的诊断性发育量表测试包括GESELL测试、Bayley测试等，能明确宝宝是否有发育迟缓以及具体是在哪一方面出现的发育迟缓。同时，需进一步询问相关病史及家庭养育情况以寻找病因，并且根据具体情况给出下一步个性化的诊疗计划和康复训练计划以及随访安排。

 

 

**智力测试**

 

 

DST是国内常用的筛查性发育测验，DST的分数一般85分以上正常；70-85分可以通过加强训练2-3月后再行复测；70分以下则建议进一步进行诊断性发育测验以明确有无发育迟缓的情况。
