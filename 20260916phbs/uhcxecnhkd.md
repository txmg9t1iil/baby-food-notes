# 一年一个新台阶  今年排名再升2位 我院连续五年荣获“中国地级城市医院竞争力百强医院”

> 更新时间：2026-09-16 (UTC+8)

3 月25-26 日，由权威医院管理机构——香港艾力彼医院管理研究中心主办的 2017 中国医院竞争力论坛在广州举行。在这个多层级医院院长分享交流的平台上，艾力彼发布“中国医院竞争力排行榜”最新排名，绵阳市中心医院位居“2016中国医院竞争力-地级城市医院百强”第48位，较2015年上升了2位，较2012年上升了20位。我院已是连续5年荣获百强殊荣。同时，绵阳市中心医院位居“2016届四川省区域医院30强”第6位。我院党委副书记何梅代表医院在大会上领奖。

**【第三方医院评价权威——香港艾力彼医院管理研究中心】**

作为医院管理研究的领航者，艾力彼长期以来一直在研究中国医院发展的变迁、潜在的机会，以及这些机会对行业的长远影响。同时，每年推出的“中国地级城市医院竞争力100强”榜单是通过对中国各地级城市医院定量排序，从医院规模、医疗技术、经济运行三大维度和诸多二级指标进行分析后得出的结果。作为第三方的客观评价，香港艾力彼医院管理研究中心的排行榜得到了业内的广泛认可和卫生主管部门的认同。每年发布的竞争力排行榜单为各层级医院的可持续发展和提升竞争力树立了标杆。中国医院竞争力排名榜最终榜单的发布，将有助于建立医院评价体系，推动不同层级医院的发展及协作。
